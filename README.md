Project Overview
This project investigates the use of different machine learning models to forecast stock prices and evaluate their performance. The study focuses on comparing models across multiple equities and analysing inter-stock relationships.

The main objectives are:
Predict stock prices using historical data
Compare performance of multiple machine learning models
Analyse relationships between different stocks
Evaluate model effectiveness using statistical metrics

Machine Learning Models Used

Long Short-Term Memory (LSTM)
Linear Regression
Random Forest Regressor
XGBoost Regressor

Stocks Analysed

Tesla (TSLA)
NVIDIA (NVDA)

Inter-Stock Analysis
The project explores relationships between stocks by identifying correlations and dependencies between TSLA and NVDA.

Evaluation Metrics

Mean Absolute Error (MAE)
Mean Squared Error (MSE)
Root Mean Squared Error (RMSE)
